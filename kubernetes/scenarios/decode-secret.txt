Decode the contents of the existing secret named database-data in the database-ns namespace and save the decoded content
into a file located at decoded.txt

k get secret database-data -n database-ns --template={{.data.DB_PASSWORD}} | base64 -d >> decoded.txt

Create a Kubernetes Secret named database-app-secret in the default namespace using the contents of the file database-data.txt 
kubectl create secret generic database-app-secret --from-file=database-data.txt

kubectl get secret database-app-secret -o jsonpath="{.data.database-data\.txt}" | base64 --decode
